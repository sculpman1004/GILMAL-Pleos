# 길말 (GILMAL) — Pleos 차량 환경 프로토타입

길말은 주행 환경과 운전자 유형에 따른 안내를 살펴보는 차량용 앱 프로토타입입니다. Pleos Connect 에뮬레이터에서 실행해 내비게이션, 날씨 및 차량 상태 조회를 시험했습니다.

## 주요 기능 및 상태
- Pleos NaviHelper: 목적지 안내와 현재 목적지 조회를 에뮬레이터에서 확인했습니다.
- Open-Meteo: 위치 및 목적지 기준 날씨 조회를 구현했습니다. 예보는 실제 관측이나 경로 전체 상황을 보장하지 않습니다.
- Pleos Vehicle: 차량 상태를 조회하며, 값을 얻지 못한 항목은 확인 불가로 표시합니다. 실제 차량 검증은 아직 하지 않았습니다.
- 위험 안내 및 주행 시나리오 일부는 모의 데이터로 동작합니다.
- 음성 안내는 에뮬레이터에서 음성 엔진 연결 실패가 확인되어 해결이 필요합니다.

## 실행
Android Studio에서 이 폴더를 열고 Gradle 동기화 후 Pleos Connect v2.1.0 에뮬레이터(API 34)에서 실행합니다. 빌드에는 Android SDK 37 및 Pleos SDK 저장소 접근이 필요합니다. 기기와 SDK 권한 및 지원 상태에 따라 기능이 달라질 수 있습니다.

저장소의 `app-release.apk`는 서명된 릴리스 APK입니다. APK 서명은 확인했으며, 별도의 릴리스 APK 설치 실행은 아직 검증하지 않았습니다. 기존 설치본과 서명이 다르면 덮어쓰기 설치가 실패할 수 있습니다.

이 앱은 시연용 프로토타입이며 차량의 경고 장치나 운전자의 점검을 대체하지 않습니다.
