# 길말 (GILMAL)

**운전 경로를 중심으로, 그 길의 날씨·빛·도로 환경을 생활 속 문장으로 미리 들려주고 출발 전 차량 안전 점검까지 이어 주는 Pleos Connect 차량용 주행 보조 앱**

> 2026 현대자동차그룹 차량용 앱 개발 공모전 출품작 · 팀 sculpman

---

## 한눈에 보기

| 일반 경고 | 길말 (가족 모드) |
|---|---|
| “시간당 10mm의 비가 예상됩니다.” | “토독토독 빗소리가 들릴 만큼 비가 와요. 길에 작은 물웅덩이가 생겨요. 와이퍼를 켜고 천천히 가요.” |
| “일몰 17:21” | “지금은 환하지만, 도착할 오후 6시쯤에는 해가 져서 깜깜해져요. 출발 전에 전조등이 잘 켜지는지 같이 확인해요.” |

- **이동 경로 기준 사전 안내** (출발 전에는 15초 안팎 요약, 나머지는 비 구간·해 지기 전·휴게 시간에 그때그때 짧게): Pleos 내비의 목적지·남은 시간으로 도착 예정 시각을 계산하고, 도착할 때까지의 예보와 목적지 일몰 시각, 내비 경로 정보(터널·휴게소·주의 구간)로 출발 전 브리핑을 만듭니다.
- **생활 문장 안내**: 숫자(풍속·강수량)는 판단 근거로만 쓰고, 기상청 체감 안내를 바탕으로 한 표현과 행정안전부 국민행동요령의 운전 행동을 들려줍니다.
- **운전자 유형별 안내**
  - 가족: 아이도 알아듣는 비유로 ‘빨리 달리면 어떻게 되는지’까지 설명 → 아이가 이해하고 “아빠, 천천히!”라고 먼저 반응
- **오늘은 이런 날**: 출발 전 첫 문장으로 오늘 날씨를 한 장면으로 그려 줍니다.
  - 가족: “오늘은 앞이 잘 안 보일 만큼 쏟아지는 비가 오고, 나무가 쓰러질 만큼 바람이 세게 부는 날이에요. 우리 차도 바람에 흔들릴 수 있어요. 이런 날 빨리 달리면 위험해요.”
  - 초보운전(안심형 코치): “… 다리 위에서 차가 조금 흔들려도 정상이에요. 앞차와 거리를 넉넉히 두고 내 속도로 가면, 오늘도 충분히 잘 갈 수 있어요.”
    - 거리 코치: 앞차가 표지판을 지난 뒤 “하나, 둘, 셋”(비·밤에는 넷)을 세어 거리를 확인
  - 화물차(사실·위험·조치형): “… 높은 적재물은 돛처럼 바람을 받습니다. 끈 풀림 위험이 큽니다. 떨어진 적재물 하나가 뒤차 앞유리를 뚫는 사고가 됩니다. 주행 중 사이드미러로 적재물과 뒤차를 수시로 확인하십시오.”
    - 불량 적재 주의: 고정 끈은 주행 진동으로 풀림 → 덮개 펄럭임·기울어짐 발견 시 즉시 정차 후 재결박
    - 경각심: 적재물 추락방지 의무 위반은 교통사고처리특례법상 12대 중과실 → 사람이 다치면 종합보험 가입과 관계없이 형사처벌 대상 · “한 번의 결박 불량이 두 가정을 무너뜨립니다”
  - 시연 화면의 **비바람** 버튼으로 바로 확인할 수 있습니다.
  - 초보운전: 좁아지기 쉬운 시야를 넓혀 주는 ‘어디를 볼지’ 안내
  - 화물차: 날씨·도로 환경이 적재물에 주는 영향과 점검
- **위험에 맞춘 차량 점검**: 비 예보 → 타이어 공기압, 가는 도중 해가 짐 → 전조등, 공통 → 브레이크액·ABS 경고등 (Vehicle SDK로 확인 가능한 항목은 자동 조회, 값이 없으면 ‘확인 필요’)
- **A/B 음성 비교(정차·실내 평가 전용)**: 같은 가상 데이터로 수치 중심 경고 예시(A)와 길말 안내(B)를 비교하고 이해도 평가를 저장·CSV로 내보냅니다.

## 사용한 Pleos SDK·API

| 구분 | 버전 | 용도 |
|---|---|---|
| NaviHelper SDK | 3.0.5 | 내비에 설정된 목적지 조회(남은 거리·시간, 내비 조작은 하지 않음), 경로 안내 목록(터널·휴게소), 주의 구간 알림 |
| Vehicle SDK | 2.3.2 | 전조등, 브레이크액, ABS 경고등, 타이어 공기압 조회 |
| TextToSpeech SDK | 3.3.1 | 차량 음성 안내 재생 (온디바이스 → 하이브리드 → 서버 순서로 연결 시도) |
| Open-Meteo API | – | 목적지 시간별 예보(비·바람·구름·낮밤), 일출·일몰 시각 |

Pleos 음성을 쓸 수 없는 기기(일반 휴대폰 에뮬레이터 등)에서는 Android 기본 음성 → 알림음과 화면 문구 순으로 자동 대체합니다.

## 실행 방법

### APK로 실행
1. Pleos Connect Emulator v2.1.0을 실행합니다.
2. APK를 설치합니다.
   ```bash
   adb install -r apk/sculpman_길말_release.apk
   ```
3. Pleos 내비게이션에서 목적지를 설정한 뒤, 앱 목록에서 **길말**을 실행합니다.

### 소스로 실행
1. 이 저장소를 Android Studio에서 엽니다.
2. Gradle Sync를 실행합니다. Pleos SDK는 `settings.gradle.kts`에 등록된 Pleos Maven 저장소(`https://nexus-playground.pleos.ai/repository/maven-releases/`)에서 내려받습니다.
3. 실행 기기로 **Pleos Connect v2.1.0**을 선택하고 ▶(Run)을 누릅니다.

### 필요한 설정·권한
- 인터넷 연결(날씨 예보 조회). 예보를 받지 못하면 ‘확인 필요’로 표시하고 위험이 없다고 말하지 않습니다.
- `AndroidManifest.xml`에 선언된 권한: `pleos.car.permission.NAVI_ROUTE_SEARCH`, `NAVI_ROUTE`, `CAR_DOORS`, `CAR_LIGHTS`, `CAR_SAFETY`, `TTS_SERVICE`, `android.permission.INTERNET`
- 별도 API 키나 계정은 필요하지 않습니다.

## 시연 방법

1. Pleos 내비에 목적지를 설정하고 길말을 엽니다. 오른쪽 카드에 **출발 전 경로 브리핑**이 나타납니다.
2. **[▶ 출발 전 안내 듣기]**를 누르면 Pleos 차량 음성으로 브리핑을 들려줍니다.
3. 오른쪽 위에서 **가족 / 초보운전 / 화물차**를 바꾸면 같은 경로에서 말투와 안내가 달라집니다.
4. 아래 **시연 · 강풍 / 폭우 / 터널 출구** 버튼으로 모의 상황을 들을 수 있습니다(화면에 ‘시연용 모의 상황’ 표시).
5. **[테스트 도구 ›] → 음성 비교** 탭에서 A/B 비교와 이해도 평가를 할 수 있습니다(정차·실내 전용).

- `AbStudyTest`: A/B 동일 데이터 사용, 모드별 문장 차이, 강수 강도별 표현, 결빙 정보 부족 처리, A/B 요약 집계

## 안전 원칙

- 길말의 위험 단계(관심·주의·심각)는 자체 분류이며 공식 기상특보가 아닙니다.
- 예보와 모의 상황을 화면에 구분해 표시합니다.
- 데이터가 없거나 받지 못한 항목은 정상으로 보지 않고 ‘확인 필요’로 표시합니다.
- 운전 중에는 화면 조작 없이 짧은 음성 안내만 제공하며, 평가 기능은 정차 상태·실내 전용입니다.
